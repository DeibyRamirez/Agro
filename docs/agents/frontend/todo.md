# Agente Frontend (Android)

## Objetivo

Completar pantallas Figma y conectar API + repositorios.

## Prerrequisitos

Auth API y persistence layer.

## Tareas

1. Login/registro.
2. Dashboard KPIs desde API/local.
3. Potreros, Producción, Reproducción, Finanzas, Reportes, Pendientes, Más.
4. Navegación inferior unificada.
5. Edición de animal.

## Criterios de aceptación

- Flujos CRUD principales sin crash.
- UI alineada a tokens en `Design.md`.

## Verificación

Emulador API 10.0.2.2:3000, smoke en `docs/architecture/e2e-smoke.md`.
